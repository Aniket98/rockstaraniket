# PostgreSQL - Building and Installing the oracle_fdw extension

Official Link: [Github Official Guideline](https://github.com/laurenz/oracle_fdw)

Install oracle_fdw on PostgreSQL (SLES 15)

1. Install required packages

   * gcc, make
   * postgresql12-devel

2. Install Oracle Instant Client

   * Download basic + sdk packages
   * Set environment variables:
     LD_LIBRARY_PATH=/path/to/instantclient
     (optionally ORACLE_HOME)

3. Download oracle_fdw source

   * git clone https://github.com/laurenz/oracle_fdw.git
   * OR download tar.gz and extract

4. Build and install

   * make
   * make install

5. Enable extension in PostgreSQL

   * CREATE EXTENSION oracle_fdw;

   And give GRANTS to applicative user.

6. Configure usage (after install)

   * CREATE SERVER
   * CREATE USER MAPPING
   * CREATE FOREIGN TABLE
